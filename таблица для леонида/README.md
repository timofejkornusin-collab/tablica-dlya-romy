# Журнал занятий · таблица для Леонида

Готовая копия сайта [rusklasst.ru](https://rusklasst.ru) на **2 сентября 2026**, чтобы поднять **такой же журнал на другом домене** и в отдельном репозитории.

Внутри этой папки — целый проект. Новый GitHub-репозиторий создавайте **из содержимого этой папки**, а не из всего репозитория «таблица для ромы».

## Что внутри

**Как на живом rusklasst.ru:**

- шапка и кнопки: `static/index.html` (скачан с сайта, вместе с `delete-fix.js`)
- логика журнала: `static/app.js`
- оформление: `static/styles.css`, `static/mobile.css`, `static/practice-scales.css`
- вспомогательные скрипты: `find-date.js`, `practice-page.js`, `practice-reveal.js`, `practice-lock.js`, `practice-scales.js`

**Чтобы сайт запускался (с сайта это скачать нельзя, взято из рабочей программы журнала):**

- `server.py` — сервер
- `journal.py` — таблицы, расписание, прогресс
- `pdf_import.py` — разбор PDF в практические задания
- `запустить.bat` — запуск на Windows
- `data/banks/ege-10.json` — набор «Задание 10 ЕГЭ»

Сюда уже входят правки сентября 2026: шапка таблицы (плашка под именем, «К списку» по центру), разделение формулировки и предложения в заданиях 15 и 17–21, загрузка PDF в практике.

**Намеренно не копировалось** (чужие данные и секреты):

- списки учеников, ответы, загруженные PDF
- логин и пароль педагога rusklasst.ru
- продакшеновый `server.py` с сервера Beget и скрипты выкладки на `45.153.190.116`

Поэтому **ученики Ромы на копии не появятся**. Журнал будет пустой. Это тот же сайт, но со своими учениками.

## Как сделать новый репозиторий

1. На GitHub: **New repository**, например `tablica-dlya-leonida` (латиница удобнее, чем кириллица в адресе).
2. На компьютере скопируйте **все файлы из этой папки** в пустую папку проекта.
3. В той папке:

```powershell
git init
git add .
git commit -m "Первая версия журнала для Леонида"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/tablica-dlya-leonida.git
git push -u origin main
```

Если репозиторий `tablica-dlya-leonida` уже есть — скопируйте файлы поверх и сделайте `git add .`, `git commit`, `git push`.

## Как запустить у себя на компьютере

1. Установите [Python](https://www.python.org/downloads/) и отметьте **Add python.exe to PATH**.
2. Для импорта заданий из PDF (не обязательно для самой таблицы):

```powershell
pip install pymupdf pypdf
```

3. Дважды откройте `запустить.bat` **или**:

```powershell
python server.py
```

4. Вход педагога первый раз:
   - логин: `учитель`
   - пароль: `учитель`  
   Сразу смените пароль в настройках. Не оставляйте этот пароль на настоящем сайте.

5. Нажмите **«Добавить ученика»** и соберите журнал Леонида заново.

Окно запуска не закрывайте, пока работаете с таблицами.

## Как повесить на другой домен (Beget / VPS)

Нужен сервер с Python 3 и Nginx. Папку проекта обычно кладут в `/var/www/journal`.

1. Загрузите файлы на сервер.
2. Запустите `python3 server.py` (по умолчанию порт **8765**). На постоянную работу удобен systemd-сервис.
3. В Nginx для **нового** домена (не rusklasst.ru) проксируйте на `127.0.0.1:8765`.

Пример:

```nginx
server {
    listen 80;
    server_name НОВЫЙ-ДОМЕН.ру;
    client_max_body_size 32m;

    location / {
        proxy_pass http://127.0.0.1:8765;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_read_timeout 120s;
    }
}
```

4. Выпустите HTTPS (Let's Encrypt / панель Beget).
5. Откройте домен, войдите как педагог, добавьте учеников.

**Не запускайте** скрипты выкладки, которые прописаны на rusklasst.ru и IP `45.153.190.116` — они обновят чужой сайт.

Да, **экран и кнопки** — как на живом сайте на дату копии (включая шапку, поиск по дате, кнопку «Выдать файл»).
