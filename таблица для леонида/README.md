# Таблица для Леонида

Отдельная копия журнала занятий **без учеников и паролей с rusklasst.ru**.

Снимок кода: **9 сентября 2026** — ссылка для ученика без Pinggy, без автоматического кабинета учителя через nginx, вход помнится 30 дней.

Это **не** репозиторий Ромы. Не смешивай `data/students.json` и `auth.json` с боевым сайтом.

## Как сделать отдельный GitHub

1. Создай **новый приватный** репозиторий (например `tablica-dlya-leonida`).
2. Скопируй **только содержимое этой папки** в корень нового репо — не весь `tablica-dlya-romy`.
3. Первый коммит из этой папки.

Публичный репозиторий `leonid` для этого кода не подходит: исходники журнала туда не кладём.

## Запуск на компьютере

Нужен Python 3.

```
запустить.bat
```

или

```
python server.py
```

Открой в браузере адрес, который напишет сервер (обычно `http://127.0.0.1:8765`).

Логин преподавателя по умолчанию, если нет `auth.json`: **учитель** / **учитель**. Смени пароль после первого входа.

Список учеников пустой — заведи своих через интерфейс.

Банки «Задание 1–3» лежат в `seed-banks/`. После запуска их можно поставить в `data/banks/` (скопируй JSON) или загрузить PDF из `seed-pdfs/` через «Практику».
